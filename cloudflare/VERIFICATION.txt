ROLLBACK
--------
Command:
  python3 - <<'PY'
  import pathlib, shutil, subprocess, tempfile
  root = pathlib.Path.cwd()
  tracked = '.gitignore build/common.js build/extension.js build/web.js package.json src/data/constants/app.js src/index.ejs src/target/extension/manifest/index.js'.split()
  new = 'build/environments.js cloudflare/.dev.vars.example cloudflare/CF_ENVIRONMENT.diff cloudflare/README.md cloudflare/contracts/openapi.yaml cloudflare/contracts/v1-routes.json cloudflare/environments.json cloudflare/migrations/0001_initial.sql cloudflare/package.json cloudflare/src/index.js cloudflare/test/build-config.test.js cloudflare/test/contract.test.js cloudflare/VERIFICATION.txt cloudflare/wrangler.toml cloudflare/ROLLBACK.sh'.split()
  with tempfile.TemporaryDirectory(prefix='raindrop-rollback-') as directory:
      copy = pathlib.Path(directory)
      for path in tracked:
          destination = copy / path
          destination.parent.mkdir(parents=True, exist_ok=True)
          shutil.copy2(root / path, destination)
          destination.with_name(destination.name + '.orig').write_bytes(subprocess.check_output(['/usr/bin/git', 'show', f'HEAD^:{path}']))
      for path in new:
          destination = copy / path
          destination.parent.mkdir(parents=True, exist_ok=True)
          shutil.copy2(root / path, destination)
      result = subprocess.run(['/bin/sh', str(copy / 'cloudflare/ROLLBACK.sh'), str(copy)], capture_output=True, text=True)
      if result.returncode: raise SystemExit(result.returncode)
      restored = sum((copy / path).read_bytes() == subprocess.check_output(['/usr/bin/git', 'show', f'HEAD^:{path}']) for path in tracked)
      removed = sum(not (copy / path).exists() for path in new)
      print(f'rollback copy artifacts before={len(tracked) + len(new)} restored_tracked={restored} removed_new={removed}')
  PY
Input:
  Copy of the modified branch; rollback was run only inside the temporary copy

Manual follow-up
----------------
Current preview acceptance is complete on workers.dev. The custom domain needs
an active Cloudflare zone before it can replace the temporary URL. Preview
secret list is currently empty; real secret values are required before future
routes use BETA_ACCESS_PASSWORD, SESSION_SECRET, or ENCRYPTION_KEY.
